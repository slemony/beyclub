# CLAUDE.md

Operating manual for this repo, **split by function** under
[`docs/claude/`](docs/claude/). Read only the file that matches your task —
you don't need all of them.

| If you're… | Read |
|---|---|
| Getting oriented, running the app, or committing | [docs/claude/overview.md](docs/claude/overview.md) |
| Touching data, or tracing how data reaches the UI | [docs/claude/data-architecture.md](docs/claude/data-architecture.md) |
| Adding a tuned modding build to a blade | [docs/claude/custom-builds.md](docs/claude/custom-builds.md) |
| Editing any other hand-curated data file | [docs/claude/curated-data.md](docs/claude/curated-data.md) |

For the **rationale** behind the data and attribution model (not the
mechanics), read [README.md](README.md). This manual is the how; the README is
the why.
