Stock at a glance

This page doesn't check stock. It installs a button that does — once — and the button only works on KGB's own site, where you're signed in. Nothing on BeyClub can read the shop for you.

Kelab Gasing Beyblade's shop is members-only: you sign in, take a place in the queue, and get 15 minutes inside to order. Clicking through five listing pages to find what's actually available spends a chunk of that.

Once installed, tapping the button while you're inside the shop gathers every page at once and shows only what's in stock, on one screen, each row linking straight to its product page.

How it goes

  1. Once: install it below, for whichever device you use.
  2. Go to the KGB shop, sign in, wait for your place in the queue.
  3. Inside the shop, tap the button. The list appears over their page.
  4. Optional: tap Rank these to see them with BeyClub's tiers attached.

What it doesn't do

  • It never signs in and never enters the queue. Run it once you're already inside — it takes no place in line.
  • It never runs on its own. No schedule, no polling; only when you tap it.
  • Nothing leaves your browser. It uploads nothing, and none of what it reads reaches BeyClub's published stock data.

It makes the same five page requests you'd make by hand, spaced out — well inside the shop's own limit.

iPhone & iPad — Shortcut (best on mobile)

One-time setup, then it lives in Safari's Share sheet:

  1. Open the Shortcuts app → + to make a new one.
  2. Add the action Run JavaScript on Web Page (search "JavaScript"; it's under Safari).
  3. Tap the script box, delete the placeholder, and paste the code below.
  4. Open the shortcut's settings (ⓘ) → turn on Show in Share Sheet.
  5. Name it something you'll recognise, e.g. KGB stock.

Then, inside the shop: Share → scroll down → KGB stock.

Android

Chrome for Android can't run a bookmarklet from a tap. Two options, in order of how pleasant they are:

  • Firefox + Tampermonkey — install the Tampermonkey add-on, add a new script, paste the code above. Runs properly, like the desktop version.
  • Chrome, the awkward way — bookmark any page, edit the bookmark, replace its URL with the bookmarklet code (copy it below) and name it kgb. To run it, type kgb in the address bar and pick the bookmark from the suggestions.

If it stops working

It reads the shop's own page markup, so a redesign there can break it. It'll say so plainly rather than showing you an empty list — if you see "found no product cards", that's this needing an update, not the shop being empty.
